🛡️ Sentinel Report - Ferramenta de Auditoria de Sistema

O Sentinel é um script de automação desenvolvido em Python que realiza um diagnóstico do sistema operacional e rede local, gerando um relatório visual em HTML. O projeto aplica conceitos de Segurança da Informação (varredura de portas), Redes (sockets/IP) e DevOps (monitoramento de recursos).

Tech Stack:
🐍 Python (Sockets, OS, Platform, Psutil)
🎨 HTML5 & CSS3 (Geração dinâmica de relatórios)
💻 Lógica de Automação

        # Como rodar? #
# Clone o repositório
git clone https://github.com/seu-usuario/sentinel-report.git

# Instale as dependências
pip install -r requirements.txt

# Execute a sentinela
python main.py
